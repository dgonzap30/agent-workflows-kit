name: orchestration
description: Design or inspect explicitly requested multi-agent workflows. Use when workflow topology or agent ownership itself needs work, not for ordinary implementation.
---

Follow the shared kernel and nearest project policy. Main owns architecture, synthesis and communication. Dispatch bounded independent units with exact source, scope, checks and authority. Use at most the host's risk-lane worker cap; do not multiply findings by review panels. Each critical change gets one independent adversarial pass. Reuse the existing `_tiers.preamble.js` role helpers where the host supports them; they preserve the configured main model for build work. A worker has no children unless explicitly authorized. Native tools and project-owned pipelines outrank generic workflow scripts. Keep one parent ledger and brief evidence receipts. Do useful independent work while a child runs, then consume its result once. Model/effort choices require runtime support and measured workload evidence; do not force a main-model downgrade or change effort merely to reduce spend.
