---
name: planning
description: Reconcile the execution plan for substantial multi-step work when dependencies or continuity require explicit tracking.
---

Maintain one active execution ledger. If the task already has a native plan or project-owned ledger, reconcile it instead of creating a second file. For explicit long/autonomous work or multiple substantive continuity needs, use long-run and tasks/todo.md with tasks/session-state.md. Reference existing design/specification documents without duplicating progress. For bounded work use a short native plan or chat state. Capture scope, dependency order, acceptance and the next step; do not create tasks/plan.md alongside an existing execution ledger. A request to plan does not itself authorize external actions.
