---
name: retire
description: Preserve a task and prepare a successor when the user requests handoff, an actual context failure prevents progress, or a runtime boundary requires a new task.
---

Read the active execution ledger and inspect live changes. Preserve exact paths, branch/base, commands/results, unresolved constraints, authority and one next executable action in tasks/session-state.md. Reconcile tasks/todo.md, then provide a compact successor prompt referencing those files. Do not start a new task, delete a workspace, or terminate shared processes without authorization. Repeated compaction or a large transcript alone does not require retirement; first assess the current objective and whether a short bounded continuation can complete it. Never discard unearned acceptance gates.
