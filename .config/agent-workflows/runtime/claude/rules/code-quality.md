# Code Quality

- Prefer the smallest clear change that meets the requested behavior.
- Search for an existing local pattern before introducing a helper or abstraction.
- Preserve user data and unrelated working-tree changes.
- Treat live code, configuration, and runtime evidence as more current than stale notes.
- State facts about files, services, and behavior only after checking the relevant source or surface.
